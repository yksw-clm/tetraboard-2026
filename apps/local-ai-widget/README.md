# TetraBoard Local AI

四人リバーシ・四人将棋シングルスの参加者向けChrome拡張です。通常対局・CPU対局・大会の本番画面で、解析だけを自分のMacへ渡します。[現在仕様](../../README.md#ローカルai解析widget)と[解析API](../../packages/ai/README.md#ローカル解析サービス)を参照してください。

## 導入

リポジトリルートで実行します。

```sh
mise install
bun install --frozen-lockfile
bun run --cwd apps/local-ai-widget setup:native
```

1. Chromeの`chrome://extensions`を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」から、このcheckoutの`apps/local-ai-widget/dist`を選びます。Chrome 120以降を使います。
3. 対局ページを再読み込みし、右上のwidgetで「AI起動」、続いて「有効にする」を押します。以後は端末を開かずに利用できます。tokenは補助プログラムから拡張の信頼された保存領域へ自動設定されます。

`setup:native`はmacOSのGoogle Chrome向けです。RustのローカルAIとBun製の補助プログラムを単体実行ファイルにビルドし、`~/Library/Application Support/TetraBoard/LocalAI/`へ配置します。Chromeの`NativeMessagingHosts/net.tetraboard.local_ai.json`に、この拡張のIDだけを許可して登録します。元のcheckoutを移動しても実行ファイルは残ります。

`packages/ai/.env.local`がなければローカル専用tokenを作成し、既存なら再利用します。token設定は0600、インストール先は0700です。秘密値をログ・Git・PR・チャットへ出力しません。本番の認証値とは別です。

別の場所の`dist`をChromeへ読み込む場合は、`setup:native --extension-dir /絶対パス/dist`を使います。指定先へビルド結果を配置し、そのパスから決まる拡張IDを登録します。既存の拡張IDは変更しません。`--extension-id`でIDを明示し、`--token-file`で既存の`.env.local`を指定することもできます。Chromeに読み込むフォルダーを変えた場合は再登録してください。

対応ページは`https://tetraboard.net`、開発環境、`http://localhost:5173`、`http://127.0.0.1:5173`です。公開Serviceや本番Webへ拡張をデプロイする操作はありません。

## 使い方

「AI起動」「AI停止」「再起動」はMac上のAIサービスを操作します。widgetが無効なときも使えます。「AI停止」は探索・候補とAIプロセスを終了します。「再起動」は古い候補を消し、有効なwidgetの本人手番なら新しい検討を始めます。状態は約3秒ごとに確認し、操作中は重複操作を止めます。手動で起動済みのAIなど、ポート3002を別プロセスが使用している場合は停止・再起動せず、端末での停止を案内します。

本人手番で自動検討し、着手まで同じ探索を続けます。「解析・再解析」は現在手番の人について手動で新しい検討を始め、「検討停止」は探索と候補を消してAIサービスは残します。検討停止後の同じ局面では自動再開しません。「無効にする」はそのタブを無効にします。最後に有効にした1タブだけが対象です。非表示・切断・脱落・終局・局面変更でも検討を停止し、復帰時は最新受信の局面から再開します。

リバーシはLv6と同じ探索方式の継続検討AIに一本化し、Lv5／Lv6を選びません。探索木・乱数列・訪問数を保持し、木の保持上限後も試行を続けます。①②③は訪問数優先です。参考評価は推奨手後の探索内の単独1位率で、対人勝率ではありません。同率1位を含まないため合計100%にならないことがあります。完走した試行がなければ評価未取得です。[過去のLv6測定](../../packages/ai/docs/lv6-candidate.md)は2秒上限で実施した記録で、継続検討の棋力評価ではありません。

将棋は三人攻撃禁止ON／OFFと脱落後にも対応します。移動候補を盤上の矢印で示し、駒打ちは移動先の番号と候補欄の「飛打」などで示します。同じ移動先の番号はまとめます。候補欄には移動元・移動先・成り／不成、手番の陣営から見た参考評価値と完了深さを表示します。評価値は勝率ではありません。着手は通常の盤面・持ち駒・成り選択を操作します。矢印と番号はクリックを透過します。

右上のカードはヘッダーで移動し、折り畳めます。結果は約1秒ごとに更新します。折り畳み中も検討します。

## 更新と接続失敗

四人将棋には進行中の棋譜を取得する`analysis-replay` API対応版のWorkerが必要です。対応版の反映後、widgetの「AI停止」を押し、`setup:native`を再実行します。Chromeの拡張管理画面で拡張を再読み込みしてから、対局ページも再読み込みして「AI起動」を押してください。Chrome全体の再起動は通常不要です。

旧版から移行する場合は、端末で起動中の`serve:local`をCtrl+Cで終了してください。従来の`setup:local`・`serve:local`と設定画面へのtoken登録も、手動起動の代替手段として利用できます。Native Messaging未登録でも手動AIでの検討を維持します。

補助プログラムへ接続できない場合は`setup:native`の登録先とChromeへ読み込んだフォルダー／拡張IDを確認します。起動失敗の詳細はインストール先の`service.log`に記録します。補助プログラムは固定のローカルAIだけを実行し、ページから任意コマンド・パス・PIDを受け付けません。

旧Serviceでは更新案内を表示します。棋譜を取得できない・履歴が不足する・受信局面と再生結果が合わない場合は、推測した局面を解析せずエラーを表示します。ローカル解析要求の本文上限は256KiBです。サービス再起動や通信失敗後は「解析・再解析」で再開できます。拡張からの進捗取得が15秒途絶えた探索はサービス側でも停止します。

## 停止・削除

widgetの「AI停止」を押します。補助プログラムとの接続終了（Chrome終了・拡張の再読み込み／無効化／削除）でも、補助プログラムが起動したAIを終了します。通常終了を2秒待って応答しなければ、その子プロセスだけを強制終了します。タブを閉じただけではAIサービスを終了せず、探索は取消または15秒の失効で停止します。

補助プログラムも削除する場合は、AI停止後に`~/Library/Application Support/Google/Chrome/NativeMessagingHosts/net.tetraboard.local_ai.json`と`~/Library/Application Support/TetraBoard/LocalAI/`を削除します。拡張自体はChromeの拡張管理画面で削除し、対局ページを再読み込みすると追加表示が取り除かれます。

## 開発と確認

```sh
bun run --cwd apps/local-ai-widget typecheck
bun run --cwd apps/local-ai-widget test
bun run --cwd packages/ai check
```

成果物は`dist`とユーザーのApplication Support配下でGit対象外です。通常のWebビルド・配信には含めません。ブラウザを起動する自動テストは追加していません。実際のChromeでAI起動・停止・再起動、拡張再読み込み時の終了、候補番号・将棋の矢印・駒打ち・成り選択・着手・リサイズ・ズーム・ドラッグを単発確認してください。
