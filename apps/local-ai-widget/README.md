# TetraBoard Local AI

四人リバーシ・四人将棋シングルスの参加者向けChrome拡張です。通常対局・CPU対局・大会の本番画面で、解析だけを自分のMacへ渡します。[現在仕様](../../README.md#ローカルai解析widget)と[解析API](../../packages/ai/README.md#ローカル解析サービス)を参照してください。

## 導入

リポジトリルートで実行します。

```sh
mise install
bun install --frozen-lockfile
bun run --cwd packages/ai setup:local
bun run --cwd apps/local-ai-widget build
bun run --cwd packages/ai serve:local
```

1. Chromeの`chrome://extensions`を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」から、このcheckoutの`apps/local-ai-widget/dist`を選びます。Chrome 120以降を使います。
3. 拡張の設定画面を開き、`packages/ai/.env.local`の`AI_LOCAL_TOKEN=`より後の値を貼り付けて保存します。このtokenは本番の認証値ではありません。ファイルや値をGit・PR・チャットへ貼り付けないでください。
4. 対局ページを再読み込みし、右上のwidgetで「有効にする」を押します。ローカルAIの端末を起動したまま利用します。

対応ページは`https://tetraboard.net`、開発環境、`http://localhost:5173`、`http://127.0.0.1:5173`です。公開Serviceや本番Webへ拡張をデプロイする操作はありません。

## 使い方

本人手番で自動検討し、着手まで同じ探索を続けます。「解析・再解析」は現在手番の人について手動で新しい検討を始め、「停止」は探索と候補を消します。停止後の同じ局面では自動再開しません。「無効にする」はそのタブを無効にします。最後に有効にした1タブだけが対象です。非表示・切断・脱落・終局・局面変更でも停止し、復帰時は最新受信の局面から再開します。

リバーシはLv6と同じ探索方式の継続検討AIに一本化し、Lv5／Lv6を選びません。探索木・乱数列・訪問数を保持し、木の保持上限後も試行を続けます。①②③は訪問数優先です。参考評価は推奨手後の探索内の単独1位率で、対人勝率ではありません。同率1位を含まないため合計100%にならないことがあります。完走した試行がなければ評価未取得です。[過去のLv6測定](../../packages/ai/docs/lv6-candidate.md)は2秒上限で実施した記録で、継続検討の棋力評価ではありません。

将棋は三人攻撃禁止ON／OFFと脱落後にも対応します。移動候補を盤上の矢印で示し、駒打ちは移動先の番号と候補欄の「飛打」などで示します。同じ移動先の番号はまとめます。候補欄には移動元・移動先・成り／不成、手番の陣営から見た参考評価値と完了深さを表示します。評価値は勝率ではありません。着手は通常の盤面・持ち駒・成り選択を操作します。矢印と番号はクリックを透過します。

右上のカードはヘッダーで移動し、折り畳めます。結果は約1秒ごとに更新します。折り畳み中も検討します。

## 更新と接続失敗

四人将棋には進行中の棋譜を取得する`analysis-replay` API対応版のWorkerが必要です。対応版の反映後、解析端末の既存ServiceをCtrl+Cで終了し、`bun run --cwd packages/ai serve:local`で起動し直します。拡張をビルドし直し、Chromeの拡張管理画面で再読み込みしてから、対局ページも再読み込みしてください。

旧Serviceでは更新案内を表示します。棋譜を取得できない・履歴が不足する・受信局面と再生結果が合わない場合は、推測した局面を解析せずエラーを表示します。ローカル解析要求の本文上限は256KiBです。サービス再起動や通信失敗後は「解析・再解析」で再開できます。拡張からの進捗取得が15秒途絶えた探索はサービス側でも停止します。

## 停止・削除

widgetの「無効にする」を押し、解析端末でCtrl+Cを押します。拡張自体を無効化・削除する場合はChromeの拡張管理画面で操作し、開いている対局ページを再読み込みすると追加表示が取り除かれます。

## 開発と確認

```sh
bun run --cwd apps/local-ai-widget typecheck
bun run --cwd apps/local-ai-widget test
bun run --cwd packages/ai check
```

成果物は`dist`でGit対象外です。通常のWebビルド・配信には含めません。ブラウザを起動する自動テストは追加していません。実際のChromeで候補番号・将棋の矢印・駒打ち・成り選択・着手・リサイズ・ズーム・ドラッグ・停止を単発確認してください。
