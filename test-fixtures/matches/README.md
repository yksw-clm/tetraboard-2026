# 固定保存棋譜

`87a832a3b4c836da45b384651e2cf3ffd45f2b4b` の公開エンジンと既存ブラウザfixtureから一度生成した、通常初期局面からの合法な棋譜です。期待フレームは実行時に再生成しません。保存用元JSONの文字列はプロパティ順と省略形も互換契約に含みます。

リバーシの両モードの通常終局・外部脱落、将棋の両モードの着手・外部脱落・引分と、引分提案を省略した旧形式を保持します。旧形式は当該省略形の再現で、本番収集データではありません。`checkpoints` は初期・途中・終局とパス・成り・駒打ち・引分の表示を固定します。JSONの追加時は作成元コミット、受理されるイベント列、固定ID・日時を記録し、既存fixtureを期待値更新で置き換えません。

Workerの保存・公開応答、Webの局面復元、Chromium／WebKitの直接アクセス・再読込・操作・失敗からの再試行で共用します。
