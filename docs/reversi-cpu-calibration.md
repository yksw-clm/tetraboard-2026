# 通常リバーシの補充CPU較正

レート戦で使う補充CPUの候補を、通常リバーシのルールエンジンで比較した測定記録です。運用のCPU段階・基準レートは、開発環境での対人試遊を含めて決定します。

## 測定条件

- Egaroucid Console 7.8.2（`0c1b84ef12829b68b6d178deb35e2630e7ab5a18`）を、開発環境用と同じ `Dockerfile.reversi` でビルドします。AVX2・動的ハッシュ・1スレッド・ハッシュレベル18で、定跡は無効です。各着手前に置換表を消去し、盤面と手番を送ります。
- 標準レベル1・2・4・8と、レベル1の探索手を各手25%・50%・75%の確率で使う設定を比較します。弱体化設定で残りの手は合法手から一様に選びます。比較基準にはTetraBoardの従来Lv2（`local2`）を使います。
- seedから合法手を6〜9手選んで序盤を作ります。回転・反転と、手番を基準にした石色の置き換えで同じになる序盤を除きます。較正用の96序盤と評価用の64序盤で重複を除き、各序盤で全28組を黒白入れ替えで2局ずつ対戦させます。弱体化の乱数系列は序盤seedと設定ごとに固定し、黒白を入れ替えても同じ系列を使用します。
- ルールエンジンで全着手・自動パス・終局を判定します。CPUの不正応答・期限超過は測定失敗として扱います。勝ちは1、引き分けは0.5、負けは0です。
- 較正用の結果だけでEloの期待得点に当てはめ、`local2` を1500に固定します。完勝した組の推定を有限にするため、各組の両側に半勝ずつ加えます。95%区間は序盤単位で2,000回復元抽出します。
- 評価用ではEloを固定し、予測得点と実得点の平均二乗誤差を常に0.5と予測した場合と比較します。候補間の区別は、評価用の直接対戦で強い側の得点率の95%区間が0.5を超えるかを確認します。この区間は各組の記述用です。

## 再実行

```sh
docker build --platform linux/amd64 -f packages/ai/Dockerfile.reversi \
  -t tetraboard-ai:reversi-dev-local packages/ai
bun run --cwd packages/ai study:reversi-calibration \
  results/reversi-calibration-v1/measurement.json tetraboard-ai:reversi-dev-local
```

`--smoke` を付けると較正用・評価用各2序盤で実行します。`TETRABOARD_REVERSI_CALIBRATION_PROCESSES` は同時実行プロセス数で、既定4、上限8です。結果JSONにはエンジンと評価ファイルのハッシュ、測定コードとルールエンジンの識別子、seed、全棋譜、集計結果を保存します。較正処理は明示的なコマンドで実行します。

## 測定結果

2026-11-10に実施しました。ルールの対象はdevelop `0e111b751bc728584f4b645f83ba2ed8debbfad7`、測定コード・ルールのSHA-256は `ae5e348d635655d4135becae0b033abbc0ce4b6b6d74c9e12f40d6bf02c0a4a9` です。macOS 27.0.1 arm64、Bun 1.4.4、OrbStackのLinux amd64で、イメージ `sha256:ec2d532dde55ba67161dd35e39344a6ef2b73b9a6dbae959cc21c9ee5492bb77` を4プロセスで実行しました。測定に約270秒かかりました。

全局が満盤または双方パスで終局しました。評価用3,584局の平均二乗誤差はEloで **0.05330**、常に互角を予測する場合は **0.24756** でした。誤差の改善量は **0.19426**、序盤単位の95%区間は **0.18928〜0.19913** です。

評価用の隣接する6組で、上位候補の得点率の95%区間はすべて0.5を超えました。7設定とも対人試遊の候補とします。50%設定は、基準に使った従来Lv2に60勝62敗6分で最も近い成績でした。25%設定は従来Lv2に27勝96敗5分、75%設定は104勝22敗2分でした。

暫定Eloは従来Lv2を1,500に置いたCPU間の相対値です。対人試遊では、まず最弱の25%設定が遊びやすいか、50%設定が認定戦の出発点に適するかを確認します。開発環境の実測は標準レベル4で実施済みです。[開発環境の実測結果](https://github.com/yksw-clm/tetraboard-2026/pull/315)
