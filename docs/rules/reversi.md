# 通常リバーシのルール

この文書は通常リバーシ（ゲームID `reversi`）のゲーム固有ルールの正本です。認証、参加、通信、時間設定、チャット、保存・集計の共通仕様はREADMEを参照します。

## 盤と進行

- 8×8の盤、黒と白の2人で対局します。モードの区別はありません。
- 座標は左上をA1、右下をH8とします。初期配置は黒E4・D5、白D4・E5の4枚です。
- 開始・再戦ごとに黒白をランダムに割り当て、黒から交互に着手します。
- 空きマスに置いて縦・横・斜めで1枚以上の相手の石を挟む手だけが合法です。複数方向で挟んだ石はすべて返します。相手の石を0枚にする手も許可します。
- 自発的なパスはできません。合法手がない手番はシステムが即座に自動パスし、時計を動かさず、着手数に数えません。自動パスは棋譜・画面に記録します。
- 盤が埋まるか、双方が連続して自動パスしたら終局します。終局時の実際の石数が多い側が勝利し、同数は引き分けです。残りの空きマスは加算しません。
- 投了（自分の手番のみ）、対局中の退室、時間切れ、通信切れの復帰期限切れは本人の敗北・相手の勝利として即時終局します。盤面を変更せず、理由を棋譜に記録します。合意による引き分け提案は設けません。

## CPU

- 人間とCPUを合わせて2席で開始します。CPUも同じ合法手、パス、時間、終局の規則に従います。
- レベル1（よわい）は合法手から一様ランダムで選びます。
- レベル2（ふつう）は石数、角、辺、合法手数と相手の応手を評価します。同評価は上から左の走査順で決定します。
- 「すぐ遊ぶ」は作成時に選んだレベルのCPU1人と準備完了のホストを配置し、ホストが開始します。CPUの手番はREADMEの共通仕様に従い、最低2秒待ってから進みます。

## 表示と棋譜

- 対局中は本人を下、相手を上に配置します。初回待機の観戦者はホストを下、対局中の観戦・公開棋譜は黒を下にします。保存棋譜の本人は下にします。
- カードは対局中の退室・切断によって移動しません。再戦待機中のカードは現在のメンバー・準備状態を表示し、前局の担当色は表示しません。
- 盤面に担当色の方向差はありません。観戦・保存棋譜はカードと盤面を180度ずつ回転します。基準座標と棋譜の座標は変えません。
- 自分の手番の合法手を丸い点、直前の着手をオレンジ枠で表示します。パス・投了などでは枠を移動しません。待機中は着手できません。
- 終局後は前局の最終局面から棋譜モードに入り、結果は「結果」から確認します。次局開始まで前局の棋譜と結果を保持します。
- 初期局面、着手、自動パス、投了・退室・時間切れ・通信切れを棋譜で確認できます。棋譜の局面では合法手の点を表示しません。
