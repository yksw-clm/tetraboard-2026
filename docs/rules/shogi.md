# 通常将棋のルール

この文書は通常将棋（ゲームID `shogi`）のゲーム固有ルールの正本です。2026-10-09に開発者が以下の仕様を承認しました。認証、参加、時計、通信、チャット、保存・集計はREADMEの共通仕様に従います。

## 盤と着手

- 平手の9×9盤、各20枚で対局します。駒落ちと対局モードの区別は設けません。
- 陣営の内部IDは先手 `south`、後手 `north` とします。基準座標は先手を下に見た左上A1が `{x:0,y:0}`、右下I9が `{x:8,y:8}` です。
- 先手の最下段は左から香・桂・銀・金・王・金・銀・桂・香、2段目はB8に角、H8に飛、3段目に歩9枚です。後手は180度回転した配置です。
- 開始・再戦ごとに先後をランダムに割り当て、先手から交互に指します。
- 王、飛、角、金、銀、桂、香、歩の通常の移動を適用します。桂以外は駒を飛び越せません。王は捕獲せず、詰みで勝敗を確定します。
- 移動元または移動先が敵陣3段以内なら飛・角・銀・桂・香・歩が成れます。飛は龍、角は馬、その他は金の動きになります。成駒は盤上で不成に戻せません。
- 歩・香の最終段、桂の最後の2段への移動は必ず成ります。これらの段へ不成の持ち駒を打てません。
- 捕獲した駒は不成の持ち駒に戻します。持ち駒は飛・角・金・銀・桂・香・歩の最大7種類で、空きマスへ不成で打ちます。
- 二歩、打ち歩詰め、王手放置、自王を敵の利きへ動かす手、その他の不正着手は受理せず、盤面・手番を変えません。拒否で反則負けにはしません。確定した着手の取消は設けません。
- 詰みを直ちに判定します。手番側に合法手がない場合もその側の敗北です。
- 投了は自手番のみです。投了・退室・時間切れ・通信切れの復帰期限切れは本人の敗北として、盤面を変えず終局します。

## 千日手と長期戦

- 盤面の所属・駒種・成り、双方の持ち駒、手番が同じ局面が4回現れたら千日手です。駒の内部IDや提案状態は比較に含めません。
- 4回の出現を結ぶ一連の手順で、片方の着手がすべて王手だった場合、その側が連続王手の千日手で敗北します。王手をかけた局面・解除した局面の両方を扱います。
- 通常の千日手は引き分けとして保存し、再戦待機へ戻します。公式規則の先後交代による指し直しは行わず、次局は通常の再抽選です。
- 500手指了で点数に関係なく引き分けます。500手時点で王手中なら王手が途切れた局面まで延期します。詰みと連続王手の千日手などの勝敗確定を先に処理します。

## 持将棋提案

- 少なくとも一方の王が敵陣3段以内に入り、双方の王が王手されていない局面で、持将棋の裁定を提案できます。その条件を満たす場合だけボタンを表示します。
- 提案・同意・取消は手番を問わず行えます。双方が同意した同じ局面で点数を判定します。盤面・手番・手数・直前手・千日手回数を変えず、時計を停止・リセットしません。
- 着手で提案を解除します。再接続では保持し、次局開始時は空にします。提案・取消を棋譜イベントに記録します。
- 王を除く盤上と持ち駒を数え、飛・角（龍・馬を含む）は5点、その他（成駒を含む）は1点です。双方24点以上なら引き分け、24点未満の側は敗北です。
- 任意の局面での引分合意ではなく、点数裁定を伴う持将棋とします。

## 入玉宣言

- 500手未満の自手番・時間内に宣言できます。自王が敵陣3段以内、王手なし、敵陣の自駒が王を除いて10枚以上であることを検査します。
- 点数は自分の持ち駒と敵陣3段以内の自駒だけを数えます。王は0点、飛・角は成駒を含め5点、その他は成駒を含め1点です。
- 31点以上は宣言側の勝利、24〜30点は引き分けです。いずれかの条件を満たさない宣言は宣言側の敗北です。宣言は確認ダイアログを経て送信し、サーバーで裁定します。
- 未認証・観戦者・手番違い・局IDやrevisionの不一致・期限後の操作は宣言として受理しません。時間切れ等を先に処理します。

## CPUと表示

作成時のCPUレベル選択と最低2秒の待ち時間（CPUの宣言・同意による終局を含む）はREADMEの共通仕様に従う。

- CPU Lv1は合法手から一様ランダムに選びます。Lv2は駒の価値、王の安全、相手の応手を評価する探索を処理量で制限します。同じ状態・予算なら同じ手を選び、入力状態を変更しません。
- CPUも同じルール・時計を使います。勝てる入玉宣言を優先し、人間の持将棋提案が成立可能なら同意します。CPUから不成立の宣言は行いません。
- 本人を下、相手を上に表示します。初回待機の観戦者はホストを下、対局中の観戦・公開棋譜は先手を下にします。観戦・保存棋譜は180度ずつ回転できます。
- PC・スマートフォンとも、上から相手カード・相手持ち駒・盤面・自分持ち駒・自分カードとします。持ち駒の枠とカードは盤面と同じ幅にそろえ、手前は左から、奥は右から持ち駒を並べます。種類ごとに持ち駒を1枚、2枚以上は枚数を表示します。
- 盤面操作、合法手の点、成り選択、未確定着手、画像準備、直前手表示は四人将棋に従います。三人攻撃禁止、撃破数、完全優勝、戦法別戦績、戦型通知、バッジは設けません。
- 終局後は最終局面から直前局の棋譜に入り、結果は「結果」から確認します。初期局面、着手、提案、入玉宣言、外部敗北を保存・再生します。

## 規則の根拠とサービスへの適用

基本ルール、千日手、24点の合意持将棋、31点の入玉宣言、500手は[日本将棋連盟の対局規則](https://www.shogi.or.jp/match/taikyoku_rules/)と[2025年10月1日の誤植修正](https://www.shogi.or.jp/match/taikyoku_rules/taikyoku_rules_revision.pdf)を参照します。27点制は採用しません。

不正着手の拒否、指し直しを引き分け終局として保存すること、再戦の先後再抽選、持将棋提案の機械判定・操作・着手時解除、合法手なしの敗北は、開発者が承認したTetraBoardの適用仕様です。
