# 対局結果のX共有

全6ゲームと各ゲームが対応するモードで、終局後の結果ダイアログに参加者本人向けの共有ボタンを表示します。観戦者・公開棋譜の閲覧者には本人向けのボタンを表示しません。

ボタンは黒背景・白文字で、常に白いXロゴを含め、本人が1位（同率を含む）または勝利した場合は「フォロワーに自慢する」、それ以外は「結果をポストする」とします。将棋の千日手・合意などの引き分けは、同率1位でも後者です。棋譜の保存を確認する間は共有準備中とし、保存待ちは再照会、取得失敗は再試行を案内します。準備の失敗で再戦・退室を妨げません。

ボタンは本人の結果と公開棋譜URL `/matches/:matchId`、ゲーム名とTetraBoardのハッシュタグを入れたXの投稿画面を開きます。四人リバーシの単独1位は「四人リバーシ（オセロ）で1位になりました！🏆」、同順位は「同率」を付けます。2位以下は「2位でした！」、2人ゲーム・ダブルスの勝利は「勝ちました！🏆」、敗北は「対局しました。結果は敗北でした。」、引き分けは「引き分けでした。」とします。引き分けの同率順位がある場合は併記します。リバーシ系には「（オセロ）」、ダブルスには「のダブルス」をゲーム名に添えます。

Xへの投稿は利用者が本文を確認・編集して確定します。画像の自動添付、Xアカウント連携、自動投稿は行いません。ボタン押下を投稿完了と扱いません。

## 棋譜のOGP

公開棋譜の初期HTMLに対局別のOGPと `twitter:card=summary_large_image` を含めます。認証やJavaScript実行を前提とせず、公開棋譜の検索対象外設定を維持します。存在しない棋譜や取得障害では共通カードを返し、画面のエラー表示と再試行を妨げません。

画像は1200×630pxのPNGで、ゲームごとの固定画像 `/assets/ogp/:gameId.png` を使います。ルーム共有と同じ既存画像を使用し、シングルス・ダブルスで共通です。対局の最終盤面・順位・参加者名は画像に含めません。本人の成績は投稿本文で伝え、詳細は棋譜URLから確認できます。対局ごとの画像生成・保存・生成待ちは行いません。

棋譜HTMLは `no-store` で返し、存在しない棋譜や取得障害では共通画像を使います。Xなど第三者側のキャッシュ・表示・投稿済みカードの更新は保証しません。
