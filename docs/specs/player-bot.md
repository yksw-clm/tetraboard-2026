# 対局参加BOT

開発者のMacから動かすCLIです。四人将棋・四人リバーシのシングルスで、通常ルーム・大会・レートマッチに参加します。導入と操作は[CLIの案内](../../apps/player-bot/README.md)を参照してください。

## 参加と記録

1回の起動で専用登録アカウントを1〜4体指定し、最大4卓で並行動作します。BOTも既存の参加者として扱い、サービス側の参加条件・ゲームルール・マッチング・レート・戦績・大会集計に従います。大会参加者の了承は、開発者がサービス外で取ります。BOTを同卓に固定する機能はありません。

開発者が事前にGoogle／Discordで登録・ログインし、BOTと分かる表示名を設定します。CLIは表示名を変更しません。セッションCookieをCLIの非表示入力で取り込み、接続先とBOTプロフィールごとに保存・更新します。同じアカウントを複数体として起動できません。

通常ルームは作成と既存ルームへの参加に対応します。新規作成時は持ち時間5分＋秒読み30秒、四人将棋の三人攻撃禁止ONを既定にし、既存の許容設定から変更できます。既存ルーム・大会・レートでは、その設定に従います。ダブルスと、将棋の合意引分の提案・同意は対象外です。

## 思考と着手

BOTごとに専用のローカルRust AIプロセスを起動します。探索エンジンと既存widgetの既定動作は維持します。

手番受信から送信まで、思考込みで5〜18秒をランダムに選び、その時刻まで探索します。サーバーの着手期限から通信の余裕を引いた時刻を上限とし、時間不足時は5秒未満にも短縮します。自分の手番でだけ探索し、局・手番・局面の変更、切断で古い探索を破棄します。

期限までに有効なAI候補がなければ既存ルールの合法手を指し、代替理由をログに残します。この代替着手も通常の着手としてレート・戦績に反映されます。ネットワーク不通やMacの休止中まで時間切れを防ぐ保証はありません。

## 連戦と停止

停止するまで連戦します。通常ルームでは毎局準備し、BOTがホストなら全4席の準備と接続を確認して開始します。大会・レートは退室・席解放・必要な結果保存を確認して待機列へ戻ります。大会終了後は新しい対局へ参加せず、既存の対局を終えます。

Ctrl+Cを1回押すと新規参加を止めます。未割当なら待機を取り消し、割当済みなら開始前でもその1局を完走します。もう1回押すと明示退室して終了し、対局中なら既存の脱落・成績処理に従います。認証切れや通信障害で待機を取り消せない場合は継続を止め、サーバーの既存期限で回収されます。

## 復帰と本人確認

切断時は再接続し、同じ設定で再起動した場合も保存した待機操作・部屋世代・参加資格から復帰します。サーバー上の切断猶予や時間切れは延長しません。状態確認ができない間は新規参加せず、参加要求の結果が不明なときも新しい資格で重複参加しません。別の操作元が使用中なら自動で資格を奪いません。

認証切れ・規約への再同意が必要になったBOTは新規参加を停止します。現在の対局は参加資格が有効な限り終局まで指し、他BOTは継続します。再認証・新しい版への同意は開発者がブラウザで行います。CLIは新たな同意を自動で行いません。
