# プライバシー・利用規約・退会

この仕様は README の「プライバシー・利用規約・退会の確定仕様」から移しました（TB-150、2026-11-18）。中身は変えていません。

2026-10-12に開発者が、ゲスト名を棋譜に残す現行仕様の維持と、以下のプライバシー・規約・退会対応を承認しました。仕様・実装・検証は同じdevelop向けPRにまとめます。規約ページ・退会・常時の利用計測の実装と検証をこの変更に含めます。本番反映はリリース承認後です。実装の入口は [開発文書](../development.md#プライバシーの入口) にあります。

## ゲストと公開情報

- 未登録の利用者は「ゲスト」と呼び、個人を識別できないという意味で「匿名」と案内しません。技術上の旧DB項目名や過去の測定条件はこのために変更しません。
- ゲスト戦・CPU戦を含む終局の保存、ロビーの最近の対局、未ログインでの公開棋譜閲覧は維持します。ゲストが入力した名前は保存済み棋譜にも残ります。ゲスト名の一律置換、既存ゲスト名の一括削除、棋譜の非公開設定は今回追加しません。
- 全6ゲームの作成・CPUと遊ぶ・公開一覧からの参加では、参加確定前の案内を「対局の棋譜・結果は公開されます。」とし、規約とポリシーへのリンクを表示します。招待・観戦からの参加確認には、ゲスト名の保存・登録者の公開プロフィール・名前への個人情報入力を避ける詳細な案内も表示します。ゲスト名を含む記録の保存と公開方針は規約・ポリシーで説明し、ルーム内の再戦にも同じ方針を適用します。
- 登録者の現在の名前・アイコン・公開ID・ひとこと・お気に入りゲーム・戦績・ランキング、対局中の観戦と観戦者によるチャット閲覧も公開範囲として説明します。メール、認証プロバイダーの識別子、トークン、内部アカウントIDは公開しません。Google・Discordの名前・画像を公開プロフィールへ自動設定しない方針を維持します。
- 公開棋譜の検索対象外設定は維持します。検索対象外は閲覧制限ではなく、直接URLやAPIでも棋譜を閲覧できることを説明します。公開情報の第三者による保存・転載まで取り消せるとは約束しません。

## 文書・同意・問い合わせ

- 運営者は `chaossi`、問い合わせ先は `support@tetraboard.net` です。ログインできない登録者・ゲストからも、開示・訂正・利用停止・消去等の依頼を受け付けます。同名のゲストが存在するため、名前だけで本人と断定せず、対象URLと事情を確認して個別対応します。連絡先の実際の受信は公開前に確認します。
- 本番の `/privacy` と `/terms` に日本語のプライバシーポリシーと利用規約を提供します。未ログイン・プロフィール設定前でも直接URLと再読み込みで全文を読め、ゲーム参加・ログインなしでも読めます。両ページはサービス名、運営者、問い合わせ先、版と改定日を示します。タブ名はそれぞれ「プライバシーポリシー | TetraBoard」「利用規約 | TetraBoard」とし、直接アクセス・再読み込み・アプリ内リンクからの遷移後も維持します。
- 全ゲームのロビー、ログイン、初回設定、作成・参加、マイページから文書へ移動できます。総合ロビー公開時にOAuthのホームページ設定を `https://tetraboard.net/` へ更新し、実認証からの復帰を確認します。ポリシーには `https://tetraboard.net/privacy`、規約には `https://tetraboard.net/terms` を使用します。アプリ名は `TetraBoard` とし、ホームページとOAuth画面のリンクを一致させます。
- ポリシーは実際の取得情報、利用目的、公開範囲、Google・Discord・Cloudflareの役割、国外での取扱い、Cookie・端末内保存、保存期間、安全管理、削除・請求方法を説明します。取得情報はライブラリの既定動作と実際の保存を確認して記載し、未確認の取得・非取得やバックアップ削除期間を断定しません。
- 規約は公開棋譜と退会後の扱い、暴言・晒し・嫌がらせ・個人情報投稿・なりすまし・不正行為の禁止、通報・利用停止、投稿や画像を表示・保存するための必要範囲の許諾、サービス変更・終了、責任範囲、未成年の利用、改定を定めます。投稿物の権利の無制限な取得や、法令上認められない一律免責を定めません。
- ポリシーと規約は、[掲示板](board.md)の公開範囲（未ログインでも閲覧でき、詳細ページが検索エンジンに載ること）、期限のない保存、本人・運営の削除と退会の扱い、通報の理由と証拠の期限を説明します。
- 利用対象は13歳以上とし、18歳未満は保護者の同意を必要とします。登録・初回プロフィール設定とゲスト参加で規約への同意、年齢条件、必要な保護者同意を自己申告で確認し、生年月日・本人確認書類は収集しません。登録・初回設定・参加の操作に「続けることで、利用規約に同意し、13歳以上であること、18歳未満の場合は保護者の同意を得ていることを確認します。」と表示し、その操作で現在版への確認を送信します。同意用チェックボックスやゲストの同意版を端末へ保存する仕組みは設けません。新しいゲストアカウントは現在版への同意をサーバーに保存します。登録者は同意した文書版と日時をサーバーに保存します。同意文は通常、対象ボタンの直前に表示します。登録者が参加する将棋のレート戦ダイアログでは、同意文を省略します。対局結果のゲスト連携カードでは、Google／Discordボタンの直後に同意文を表示し、両ボタンの読み上げ用の説明にも使います。[掲示板の初回案内](board.md#初回の公開案内)にも同じ配置を使います。ログイン画面と結果画面の登録案内・連携カードは、文書リンクを連携ボタンと同意文の後に置き、文書を別タブで開いて入力内容を保持します。閲覧者への年齢保証や厳密な年齢認証をうたいません。
- 既存登録者にも初回の登録者同意を求めます。規約・公開範囲への重要な変更は事前に案内し、次の登録・参加操作の前に再同意を求めます。Google取得情報を新しい目的に使う場合は、目的を説明して同意を得る前に新用途へ利用しません。

## アカウント削除

- マイページにアカウント削除を用意します。登録に使ったプロバイダーで再認証し、現在の本人との一致を確認してから、削除する情報・残る棋譜・復元不可を示す確認操作を行います。再認証の取消・失敗では削除せず、別アカウントで認証した場合は拒否します。
- 待機・対局中は退室してから削除します。切断中の保持席も対象とし、進行中の対局の退室・投了・敗北は各ゲームの既存ルールで処理します。削除のために勝敗を変更しません。再認証と削除受付の間に参加してもサーバーが在室を再検査します。
- 削除受付を永続化した時点で新規ログイン・参加・編集を止め、全端末のセッション・ルーム資格を失効させ、公開プロフィール・ランキング・管理者一覧から除外します。棋譜は直ちに「退会したプレイヤー」と仮アイコンで表示し、公開IDとプロフィールリンクを出しません。同じ対局に複数の退会者がいても席・色・方向で区別し、対局をまたぐ退会者番号を公開しません。
- メール、プロバイダー識別子とトークン、プロフィール・画像、本人の履歴索引・戦績・バッジ・同意記録を削除します。棋譜の保存名・アカウントへの紐付け、DOに残るプロフィールや保存待ち、計測の本人識別も除去します。公開棋譜・相手の履歴・ルーム内棋譜・結果に同じ退会処理を適用し、参照先なし時の旧名へのフォールバックで退会者名を復活させません。
- 対局の手順・結果・日時・設定と、相手の履歴・戦績は維持します。退会した本人はランキングと公開戦績から除外します。同じGoogle／Discordで再登録しても新しいアカウントとし、旧履歴・戦績・バッジを紐付けません。引き継いだ元ゲスト名も退会対象とし、対局IDと参加者IDで範囲を特定します。同じ参加者IDの未引き継ぎゲスト局は巻き込まず、退会後の再取得を防ぐ対応を残します。
- 本人のフィードバック原文・添付画像・技術情報・投稿者識別・個人情報を含む編集履歴は削除対象に含めます。開発課題は個人情報を除いたIssueとして扱います。ルーム内チャットとシステムログの本人名・画像・内部参照は除去し、本文中の個人情報は依頼に応じて個別確認します。公開チャットの本人の通常投稿は削除します。掲示板の本人の投稿・返信と押したいいねは[掲示板の仕様](board.md#退会と保存期間)に従います。通報証拠は既存の7日期限を上限に管理者だけが扱い、一般画面には退会者の名前を再表示しません。
- データ除去・画像削除・プロバイダー連携解除は失敗時に再試行します。受付成功を物理削除の完了と区別し、処理中・完了の状態を提供します。受付時に発行する推測困難な削除状況確認用の資格で、セッション失効後も本人が状態だけを確認できるようにします。状況確認で旧プロフィールや削除対象の内容を返しません。外部連携解除の失敗を理由にアプリ内の利用停止を巻き戻しません。削除処理と遅延した保存・再送・アップロードが競合しても、旧名や本人索引を復活させません。
- 削除処理の再送防止・復元対策に必要な削除済み内部アカウントID、部屋・世代・プレイヤーの不透明な識別子、受付・完了時刻と状況確認資格のハッシュは、サービス運営中に非公開で保持します。削除対象索引の画像キー・解除トークンは完了時に消します。Google識別子・メールや公開プロフィールを退会履歴として無期限に残しません。バックアップ・障害ログの保存先と期限は公開前に確認し、復元時に削除を再適用します。第三者の保存や利用者の既存キャッシュまで遠隔で消せるとは説明しません。

## 保存期間・利用計測

| データ                                         | 採用する扱い                                                                                             |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| アカウントと公開プロフィール                   | 利用中は保持、退会時に利用停止と削除                                                                     |
| 棋譜・結果・ゲスト名                           | 期限削除なし。退会者情報と個別請求への対応は上記に従う                                                   |
| 公開チャット                                   | 発言から7日・各大会で最新500件まで。旧総合ロビーの発言も7日で削除。退会時は本人の通常投稿を削除。通報証拠は別の7日期限      |
| 掲示板の投稿・返信 | 期限削除なし。本人・運営の削除と退会時は本文を消す（[掲示板の仕様](board.md#退会と保存期間)） |
| 通常チャット・システムログ                     | 直近100件、部屋閉鎖で削除。退会者表示の除去を追加                                                        |
| 通報証拠                                       | 通報の既存7日期限と毎時削除を維持                                                                        |
| フィードバック                                 | 既存の投稿後180日期限を維持、退会時は本人の原文・画像等を削除                                            |
| 個別の利用計測                                 | 取得時刻から3か月以内に削除。退会前の記録には個別に削除できないものがあり、期限で自動的に削除する          |
| 長期の利用計測                                 | 個人・端末・対局を辿れるIDを含まないKPIの月次値だけを保持                                                |
| 認証Cookie・計測Cookie・端末内のゲスト名と設定 | 目的・期限・削除方法をポリシーで説明。端末内の保存をサーバー側の退会だけで全端末から消せるとは説明しない |

- 利用計測は本サービスの利用に伴って常時行い、ON/OFF設定を設けません。訪問を始めたページの種類・対象ゲーム・対局参加と開始／完了・継続利用に加え、訪問の参照元ホスト名と分類・UTM source／medium／campaign・推定端末種別を、参加導線の改善とゲームごとの利用状況・継続利用の分析に使うことを規約・ポリシーに明記します。計測の項目と仕組みは[計測の仕様](analytics.md)に従います。個別記録を完全な匿名情報と説明せず、メール・本名・OAuthトークンを分析キーに使いません。
- 計測情報を広告に利用・販売せず、他サービスをまたぐ追跡や広告・外部解析サービスへの提供を行いません。処理と保存は運営者と委託先Cloudflareで行います。退会後は新しい計測を行わず、退会前の個別記録は取得から3か月以内に削除します（[計測の仕様](analytics.md)）。開示・利用停止・消去等の依頼窓口を維持します。ブラウザがCookieを保存できない場合や通信障害の欠測を補うため、指紋採取や他サービスとの照合は行いません。

Google設定・保存情報・バックアップ・ログの確認と障害復元の手順は [運営の手順](../runbooks/privacy.md) にあります。Googleの審査結果や法的な適合性を、文書や自動テストの成功だけで保証しません。
