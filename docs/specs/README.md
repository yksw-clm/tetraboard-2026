# 仕様書

利用者から見た振る舞い（何をするか）を、機能ごとに 1 ファイルで書く場所です。どう作るかは書きません。設計判断は [docs/adr](../adr/README.md)、ゲームのルールは [docs/rules](../rules/) にあります。

## いまの状態

仕様の正本は、まだ [README.md](../../README.md) にあります。このディレクトリへ、機能ごとに順に移します。

- 移した機能は、下の一覧に足します。一覧にない機能の正本は README です。
- 移した節は README から消します。同じ内容を 2 か所に持ちません。
- 移すのは、その機能を扱うフェーズの作業と同じ変更の中で行います。移すだけの変更で内容を変えません。

## 書き方

- 1 機能 1 ファイル。ファイル名は英語の短い名前にします。
- 確かめられる振る舞いを書きます。画面の文言、状態の変わり方、制限値、保存期間などです。
- 実装の都合（テーブル名、関数名、ファイルの場所）は書きません。
- 決まっていないことは「未決」と書き、推測で埋めません。

## 一覧

まだ移した仕様はありません。
