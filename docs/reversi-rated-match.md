# 通常リバーシのレート戦

登録アカウントが通常リバーシのロビーから参加できます。持ち時間は1人3分の切れ負けです。着手・自動パス・引き分け・時間切れは[通常リバーシのルール](rules/reversi.md)に従います。

## 対戦相手と開始

対人戦を優先し、最も長く待っている人を起点にレート差100以内で探します。5秒から200以内、10秒から300以内へ広げます。15秒で条件内の相手がいなければ、本人に最も近い基準レートのCPUで補充します。同じ距離なら基準レートの低いCPUを選びます。CPU枠は通常リバーシのレート戦で最大4局・4席です。枠が埋まっている間も対人戦を探します。専用ルームに人間全員が接続してから5秒後に自動で開始します。

CPUは[較正結果](https://github.com/yksw-clm/tetraboard-2026/pull/316)に基づく次の暫定値を使います。割当時に設定の版と基準レートを固定します。

| CPU設定 | 基準レート |
| --- | ---: |
| レベル1の探索手を25%使用 | 1,297 |
| レベル1の探索手を50%使用 | 1,490 |
| レベル1の探索手を75%使用 | 1,748 |
| 標準レベル1 | 2,109 |
| 標準レベル2 | 2,385 |
| 標準レベル4 | 2,650 |
| 標準レベル8 | 3,003 |

弱体化設定では、探索手を使わない手番に合法手を一様に選びます。この着手は設定どおりの通常の着手です。AI障害で従来Lv2に切り替えた局は棋譜を保存し、認定局数とレート更新の対象から外します。

## 認定とレート更新

初期値は1,500です。有効な対人戦と補充CPU戦を合わせた最初の5局が認定戦です。レートは[将棋のレート戦](shogi-rated-match.md#レート更新)と同じElo式で更新します。勝ちは1、引き分けは0.5、負けは0です。

| 本人の状態 | 対人戦のK | CPU戦のK |
| --- | ---: | ---: |
| 認定中 | 64 | 48 |
| 認定後 | 32 | 16 |

認定5局目には認定中のKを使います。対人戦では両者、CPU戦では人間側を更新します。棋譜・レート更新・保存待ちの解除を同じD1バッチで行い、保存の再試行でも1局を一度だけ反映します。公開プロフィールでは認定後のレートを表示し、対人戦の有効局がない場合は「対人戦未経験」と表示します。

## 開発環境と公開β

`/games/reversi?matchmaking=1` から検索し、入室・結果・再参加を共通の画面で扱います。本人のレートまたは認定進捗はマイページにも表示します。新規参加は開発環境の `REVERSI_MATCHMAKING_ENABLED=true` と外部AIの接続設定で有効になります。AI Gatewayは探索レベル1・2・4・8を受け付ける版を使用します。

基準レートは従来の内蔵Lv2を1,500と置いたCPU同士の相対値です。公開βではCPU設定ごとの期待得点と実際の成績を比較し、特に最弱の25%設定と初期レートに近い50%設定を見直します。公開環境での有効化は開発環境での確認とリリース承認の後に行います。
