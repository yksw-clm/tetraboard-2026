# 設計判断の記録（ADR）

長く参照する設計判断と、そのとき却下した案の理由を残す場所です。コードを読んでも分からない「なぜそうしたか」だけを書きます。

## 書き方

- 1 判断 1 ファイル。ファイル名は `NNNN-短い英語名.md`、番号は連番です。
- 見出しは「状況」「決定」「却下した案」「影響と未決」の 4 つです。
- 決定を変えるときは、古い ADR を書き換えず、新しい ADR を足して古いほうの状態を「NNNN で置き換え」にします。
- 確かめていない外部仕様は「未確認」と書きます。確かめたら、確認日と出典を添えて書き直します。
- 計画、日程、進捗は書きません。Notion に置きます。
